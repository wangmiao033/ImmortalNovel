# 第70章 深渊裂隙

黑线扩张成缝。

缝不宽，只有半丈，却像把整层空间的“壳”硬生生掰开了一角。裂隙边缘不是石，不是光，而是碎镜般不断剥落重组的空间片层。每一块片层里都倒映着不同角度的石室、骨山、锁链，以及林渊和守门人瞬息变化的残影。

“退后。”守门人第一次用近乎命令的语气开口，“离裂隙三十丈外。”

林渊没退，只盯着裂隙深处。

里面有东西在呼吸。

不是活物的呼吸，更像某种古老结构在极深处缓慢启闭。每一次“呼”，石室里的狱纹就暗一分；每一次“吸”，断碑上的血痕就亮一寸。

塔意声音压得极低：“这不是普通裂缝。它连着更深封禁层。”

残魂骂了一句：“你这不废话吗？守门人脸都变了！”

守门人确实变了。

他腰间门牌“守”字全亮，右臂锁链绷得笔直，脚下门前狱阵第一次全开。那张一直冷硬的脸此刻没有愤怒，只有一种濒临失控前的极度专注。

“林姓后人。”他盯着林渊，“这是镇压裂口，不是你逞强的地方。”

林渊握剑，声音平稳而冷：“你怕我死在这儿，还是怕我看见这后面是什么？”

守门人眸光一沉。

“我怕你把它看醒。”

话音未落，裂隙里冲出第一波黑雾。

黑雾不是散开，而是凝成一根根细长触须，触须末端长着像骨钉般的尖端，落地即钻阵纹，沿着地面疯狂爬向四周。

古音立刻在石室上空炸响：

“镇压层泄压。”

“执行封链回收。”

“失败概率上升。”

守门人抬手结印，三道门印同时打出，锁链应印而起，朝那些黑雾触须绞杀。触须被绞断后却不消散，断口又分成更细更多的丝状黑影，像活着的孢子。

“斩不断。”守门人低喝，“只能压回去！”

林渊没等他说完，已经冲了上去。

“压不回去就全压死。”

他一剑横扫，剑光切开三道触须，触须碎段在半空扭动，竟朝他面门反扑。林渊侧身避开，左臂还是被一段黑影擦中，皮肉瞬间发灰，像被抽走了生机。

“这东西吃血肉！”残魂惊叫。

塔意厉喝：“魔骨外放，别让它进骨！”

林渊当即催动魔骨黑网，黑丝从皮下浮现，把那抹灰意硬生生逼出伤口。灰液滴在地面，石砖嗤地冒烟，直接腐蚀出一个小坑。

“它不是毒。”守门人冷声道，“是门后泄出的‘狱蚀’。”

林渊抬眼：“门后到底封的什么？”

守门人不答，只甩出一枚黑钉插进阵心。阵心震鸣，更多锁链升起，像一张铁网兜向裂隙。

第二波杀机紧跟着爆发。

裂隙边缘碎镜片层忽然齐齐翻转，每一片里都走出一道“林渊”。

不，是像林渊的人形。

他们都提剑，都带伤，都眼神冰冷。可每个人胸口都多了一道黑纹，像被门后某种东西打上的印。

“裂隙映杀。”塔意声音发沉，“会用你的招杀你。”

“那就看谁更像我。”林渊剑锋下压，直接迎上最近一道映杀影。

影子出手就是林渊常用的贴身短斩，角度狠辣。林渊侧腕格挡，两剑相撞，震感几乎一模一样。

“真会。”残魂头皮发麻。

“会形，不会心。”林渊冷声。

他故意后退半步，引对方追击。映杀影果然跟进，一剑刺喉。林渊在剑尖将至瞬间突前半寸，肩头硬吃一划，右手剑反手抹在对方腕骨处。

那是他自己最熟的“断劲点”。

映杀影腕势一断，剑路崩偏。

林渊趁势一记肘撞砸碎其胸口黑纹，影子当场碎成黑雾。

“一个。”他低声。

可镜片太多，影子还在不断涌出。

守门人那边也被逼得连退三步，门印结得越来越快，额角竟渗出细汗。

“守门印快压不住了。”塔意沉声，“裂隙在借你们的战斗加速扩张。”

林渊边斩边看，目光突然落向裂隙正上方那枚断裂刑环。

刑环原本静止，此刻却被裂隙气息牵动，开始缓慢转动。每转一圈，裂隙边缘就稳一分，像有某种“锚”在帮它固定通道。

“守门人！”林渊喝道，“上面的刑环是锚点，先打掉！”

守门人眼神一震，显然也才注意到。

“你去斩环，我拦裂口。”

“你不怕我趁机往里看？”林渊冷笑。

守门人低喝：“你先活下来再看！”

林渊不再废话，踏着断碑残台纵身跃起。

三道映杀影同时扑截。

他人在半空，时间印猛亮，视野中三影速度被拉出细微错层。林渊先一脚踩断左影肩线借力，再以剑鞘砸偏中影剑路，最后借下坠之势一剑贯穿右影眉心黑纹。

一路血与黑雾飞溅。

他硬生生冲到刑环下方，双手握剑，朝环心裂口悍然斩落。

铛——

第一剑，刑环只裂一线。

下方守门人怒喝：“再一剑！快！”

裂隙中已有更粗黑触须探出，像一只巨手要从缝里挤出来。守门人双掌结印，门牌“守”字亮到刺目，锁链一层层缠住那只黑手，却被一点点撑开。

“它在借裂隙出来……”残魂声音发抖。

林渊咬牙，再斩第二剑。

咔嚓！

刑环断成两截。

裂隙边缘立刻失稳，镜片片层疯狂抖动，映杀影成批崩碎。黑触须与黑手也被扯回缝内半尺。

可就在刑环坠落的瞬间，林渊与裂隙之间突然出现了一条最短、最直的视线。

他看见了。

只一眼。

裂隙深处不是纯黑，而是一座倒悬的巨大台座轮廓。台座四周缠满无数锁链，锁链尽头全部钉进一团难以描述的阴影里。那阴影像骨、像鳞、像人的侧脸又像兽的脊梁，边缘不断变化，没有固定形态。

它并未完全苏醒，却像早已知道有人在看它。

阴影中心，一只竖瞳般的裂线缓缓张开一丝。

林渊胸口猛地一痛，林家族纹与塔印同时灼热，像被隔空点了一下。

“别看！”守门人暴喝，声音第一次近乎失态，“闭眼！”

林渊强行收神，落地时踉跄半步，嘴角溢出一口黑血。

“你看到了什么？”残魂急问。

“看见……一座台。”林渊喘息急促，“还有被锁着的东西。”

塔意沉默数息，才低声道：“那是你现在不该直视的一角。”

守门人已冲到林渊前方，单手按在他胸口，另一手结出封门印。

“稳住心神！别让它借你的血脉定位这层！”

林渊拍开他的手，眼神冷厉：“你早知道裂隙后是那东西。”

守门人盯着他，声音低沉：

“我守在这里，就是为了不知道的人能继续不知道。”

“可你偏要知道。”

“因为我林家就是为这东西死的。”林渊一步逼近，“你让我装看不见？”

守门人沉默，眼底复杂一闪而过。

“林姓血脉确实能引门印，也会引裂隙。”

“这就是我不让你靠近的原因。”

“你不是钥匙那么简单，你是会让门后之物‘记住’的锚。”

林渊眸色骤沉。

“血夜是不是也因为这个。”

守门人没有正答，只冷冷道：

“血夜那晚，有人要夺钥，有人要灭钥。”

“你林家夹在中间，谁都不容。”

裂隙忽然再震。

这次不是触须，而是整条缝向两侧撕开半寸。石室顶部连同外层骨壁一起崩落，巨响震耳。守门人立刻转身，双手并印，门前所有锁链同时回卷，拼成一道临时封墙压向裂隙。

“林渊！”他头也不回，“借你血，压印！”

林渊没有犹豫，剑尖一划掌心，血甩向封墙中央。

血一触墙，塔纹骤亮。

封墙终于压住裂隙回缩。

古音连响三次：

“镇压回落。”

“裂隙层封闭。”

“残余通道未清。”

裂隙最终缩成一条细黑痕，暂时停住。

石室重归死寂。

守门人慢慢放下手，背后狱袍已被汗浸透。他看着那条细痕，声音低得像自语：

“再来一次，就不是这层能压的了。”

林渊擦去嘴角黑血，目光却还钉在细痕上。

“刚才那倒悬台座，像什么地方。”

守门人沉默片刻，终是开口：

“像一颗心。”

“黑塔的心。”

林渊瞳孔一缩。

守门人转头看他，眼神前所未有地凝重。

“你若再往前，见到的就是整座塔最不该被看见的东西。”

“那后面——”

“是黑塔真正的核心。”*** End Patch
