# 第98章 深渊出口开启

白光尽头，出口终于完全张开。

那不是一扇门，而是一道垂直裂幕。幕外有风、有天、有凡界灵气；幕内则是深渊余压、黑塔震鸣与追杀未止。

“出去！”守门人的声音在后方震起。

“再晚一息，出口会折返筛杀！”

林渊刚要踏入，左右两侧同时炸开。

赵家与杜家最后两支伏队从暗崖后冲出，显然等的就是这一步。前者甩网锁印，后者抬盾堵口，想把林渊卡死在幕前。

“拦住他！”

“谁都别让他先出去！”

林渊眸光一寒，剑锋一抖。

“你们真不长记性。”

他先斩右侧盾阵，三剑连点同一盾缝，盾墙当场崩开。再回身切左侧锁网，锁印被腕印门环反卷，倒缠回赵家阵手脖颈，连人带网拖进乱流。

守门人也在后方压阵，一链抽碎杜家领头者头骨。

“我只说一次！”守门人怒喝，“滚开！”

可门后裂隙也在这一刻反扑。

一道黑潮从幕内倒卷，化成数条王纹追影，直扑出口。敌我双方同时被卷，惨叫四起。

林渊逆着黑潮前冲，一剑劈开最粗那条追影，借反震跃上半空，脚尖点在崩碎盾面上，再次加速。

杜家副统领绝望扑来，想同归于尽。林渊侧身让过，反手斩首，尸体直接被出口风压撕走。

最后三步。

林渊突然听见身后塔意规则音重叠而来：

“目标离塔确认。”

“旧印携带通过。”

“后续追踪，保持。”

他没有回头，纵身撞入白幕。

一瞬天旋地转，耳边只剩风雷。

等视线重新聚焦，脚下已是深渊外缘断崖，远处山河轮廓隐现。可还没站稳，出口内又冲出两道追兵与一头王纹残影。

“还没完。”林渊低声，提剑再战。

三招之后，追兵尽死，王纹残影被一剑钉碎。

白幕开始收缩。

最后收缩前，守门人的声音穿过裂幕，低沉而远：

“出去之后，先看天。”

“再看人。”*** End Patch
