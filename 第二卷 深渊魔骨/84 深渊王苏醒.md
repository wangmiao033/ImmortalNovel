# 第84章 深渊王苏醒

那股威势不是气浪。

是“王压”。

它从古城地底一寸寸抬升，像有一颗沉睡万年的心在王座下重新跳动。城中所有活人同时一沉，修为弱的当场跪地吐血，连喊都喊不出来。

林渊胸口一闷，双腿像灌了铅。

“别硬抗正面！”塔意喝道，“这是王级意志外压，不是你现在能扛平的。”

赵家领队已经崩了，嘶声大喊：“撤！全撤！王压不是我们能碰的！”

可古阵封线早封死四门，谁退谁先被绞。杜家人硬冲西门，刚触到门线就被切成两截。白纹阵师想开传送符，符还没成，王压一落，符纸直接燃成灰。

石像王冕上的裂纹继续扩开。

暗红光在眼窝里越聚越浓，最终化成一对“半睁的眼”。它没有完整苏醒，却已经足够让整片古城颤抖。

“深渊王……”

“它真的在这城底下……”

“不对。”塔意沉声，“是王级残座，不是完整本体。可就算只是残座，也能压死你们这批。”

林渊强迫自己稳住呼吸，目光落向阵台王座印。

“王压从那里出来。”

“阵心就是阀。”

他刚要冲阵心，背后一道白影扑到。

白纹阵师满脸血，手里捏着一枚黑钉，疯狂吼道：“都得死！我先开王座，谁都别活！”

黑钉直钉阵心。

林渊反手一剑，先斩他手腕，再一脚把人踹飞。可黑钉已离手，贴着阵心边缘扎下，王座印瞬间爆亮。

轰！

第二波王压砸落。

林渊膝骨一颤，险些跪下。周围三方修士更惨，成片倒地，骨裂声连响。有人眼耳口鼻齐出血，直接被压晕。

石像王座下方，地面缓缓裂开一条长缝。

缝里探出半截黑金锁链，链上挂着破碎王纹。

“它在解锁！”残魂惊叫。

林渊眼神一厉，顶着王压冲向阵心。

赵家领队见状嘶吼：“拦住他！他若断阵，我们全得给王座陪葬！”

两名赵家死士硬撑着扑来，林渊不闪，剑走短线，两剑封喉。尸体还没倒下，他已跃到阵心上方，双手握剑，猛地刺入王座印中央。

“给我停！”

剑身与阵心硬碰，火星如雨。

王座印反震把他手臂震麻，虎口再裂。可他死死压住不松，魔骨黑网顺着剑脊反咬阵纹，时间印同步锁住阵心节拍。

塔意大喝：“再压一息！”

林渊咬牙，整个人几乎被王压按到地里，仍把剑一点点往下压。

咔！

阵心裂开一道细缝。

王座眼中的红光随之一暗。

石像抬头动作停了一瞬。

“有用！”残魂大吼。

但下一刻，古城外圈忽然传来更沉的连锁轰鸣。王座不是单点供能，而是整个古城阵网给它输血。林渊只断一缝，外圈供能立刻补上。

王压第三次升高。

林渊胸口剧痛，喉中喷出一口血，身形被反震掀飞，重重砸在残柱下。

他还没站起，王座缝隙里已浮出一截更清晰的“王影”：像半身披甲的人，又像披鳞的兽，轮廓不断变化，唯一不变的是那股冷酷到极点的俯视感。

王影对着全城发出无声咆哮。

下一瞬，城中守卫残灵与古尸守影全部暴动，朝活人疯狂扑杀。

林渊抹去嘴角血，强行起身。

“阵没破完，先得活。”

他抬剑迎上第一头暴走守影，眼神冷到极点。

“想让我死在这儿？”

“你这残王，还不够。”*** End Patch
