# 第40章 第一层完成

幽蓝裂缝像一只眼，越睁越大。

炼骨室的寒意一层层压下来，黑台上的弧线纹路明明已经暗下去，却仍有细微的光在缝隙里游走，像被什么东西从更深处拽着走。

林渊站在裂缝前，胸口起伏不大，骨缝里却在“咔咔”作响。

那不是碎裂。

是狱源灰黑之气沿着命脉刻度缓慢流转时，魔骨雏形在骨面下扣合的声音。

他能清晰感觉到，自己体内现在有三层力量在彼此咬住——

丹田塔影的重压；

魔骨黑网的沉冷；

命脉裂口里那枚黑痣的安静贪欲。

三者刚刚被狱源炼成的“桥”勉强垫住。

桥越稳，他越强。

桥越稳，门后那位也越近。

“你现在知道了吧。”塔意的声音从四周压来，“所谓融合，不是把力量揉在一起。”

“是把它们都绑在你身上。”

林渊没有回头。

他盯着裂缝里的幽蓝光。

那光深处隐约可见锁链纹路在蠕动，像一条条细小的蛇在缓慢盘旋，越盘越紧，最终绕成一个熟悉的轮廓——

【钥】。

“它在叫你。”残魂的嗓音发涩，“它想让你进去。”

“它想让我把门开大。”林渊低声。

“那你还站在这儿？”残魂咬牙。

林渊缓缓抬手。

掌心朝前。

他没有伸进裂缝。

而是把掌心贴在裂缝边缘的锁链纹路上。

冰冷刺骨。

那股冷意顺着指骨往上钻，直冲命脉刻度的裂口。

黑痣微微一亮。

像嗅到血腥味的舌头伸出来。

林渊的眼神更冷。

他在心底压住黑痣的躁动，反过来催动狱源灰黑之气，让它沿着桥梁流向掌心。

狱源之气碰到锁链纹路的瞬间，发出极轻的“嗤”声。

像铁在磨石。

裂缝里的幽蓝光微微一滞。

锁链纹路的蠕动也慢了一线。

“你在做什么？”残魂一惊。

“关门。”林渊道。

“你不是要进去？”残魂压低嗓音，“你不是被它逼着走？”

“我会走。”林渊平静，“但不是现在。”

他指尖微微用力。

狱源灰黑之气在掌心与锁链纹路之间形成一道极薄的膜。

那膜像一张纸，却硬生生把裂缝里渗出的深渊呼吸挡住一瞬。

就是这一瞬，他胸骨时间印猛地一亮。

时间错位！

他把自己“快”了半拍。

不是为了冲进裂缝。

是为了在裂缝反应过来之前，把膜打得更厚一点。

他不是在与门后那位争力。

他是在与黑塔第二层本身的刻度争一线。

争这一线，把自己的路先走稳。

滴答。

穹顶深处传来一声滴答。

不是殿堂里的滴答。

而像远处时间广场那只刻度眼在合拢时的声音。

裂缝边缘的锁链纹路猛地一紧。

幽蓝光骤然亮起。

那股深渊呼吸像潮水一样压来，试图把林渊掌心的薄膜一口吞没。

林渊喉头一甜。

骨缝里连串爆响。

魔骨黑网在这一刻被迫浮起一线，皮肤下黑纹如鳞，齐齐竖起。

他能感觉到魔骨在兴奋。

兴奋于这股呼吸。

它想吞。

林渊却在心底狠狠压住它。

“你吃得越多，门开得越大。”他在心底低喝，“我不准。”

太初吞天诀轰然运转。

不是吞裂缝里的呼吸。

而是吞自己体内的躁动。

吞魔骨的贪。

吞黑痣的渴。

吞心口翻涌的血。

把这三股躁动压成一条更紧的绳，死死勒在狱源桥梁上。

嗡——

掌心薄膜骤然凝实。

裂缝中的幽蓝光被硬生生压回去一线。

锁链纹路的蠕动也慢了。

林渊的掌心却已裂开。

血渗出，又在极冷的气息下迅速发黑。

他没有松手。

他只是低声道：

“你说要看我还能把自己当人多久。”

“那就看清楚——”

“我不会把门开在我想开之前。”

裂缝里传出一声极轻的笑。

笑意有些阴冷，有些懒散。

像一个坐在门后的人，终于承认这块骨头并不只是会往前冲。

它会收。

会藏。

会把自己的线绕进更深的结里。

“不错。”塔意的声音忽然响起，比之前更近，“你终于明白第二层的真正规矩了。”

“不是快，不是慢。”

“是‘把时间当锁，把自己当钥’。”

“锁不住门后那位，就先锁住你自己。”

林渊眼神一凝。

“这是试炼？”他问。

“这是最后一道。”塔意道，“你在第二层完成了三件事——”

“你在时间里走过路。”

“你在药池里把骨头洗出了雏形。”

“你在狱源里给自己搭了桥。”

“现在，你又学会——”

“不被门牵着走。”

话音落下，裂缝边缘的锁链纹路忽然齐齐一震。

像有人把一整面锁链垂幕从背后拉紧。

幽蓝光迅速收缩。

裂缝从原本可见门影的宽度，退回到一条细如发丝的缝。

缝还在。

但门暂时关上了。

林渊松开手，踉跄后退半步。

他低头看向掌心。

血已经止住。

伤口边缘却留下一圈淡淡的灰黑纹，像被锁链烙过。

“它给你留了个记号。”残魂低声。

“我也给它留了个记号。”林渊平静。

他说的是那层狱源薄膜。

薄膜里有他的时间刻度，有他的魔骨骨纹，有他的太初血线——

也有他的选择。

塔意没有再纠缠那扇门。

“第一阶段结束。”它冷冷宣布。

炼骨室的黑台纹路彻底熄灭。

四周的锁链垂幕缓缓退去，殿堂的压迫感随之减轻一线。

不是放过。

像是把一根绳从勒喉处移到胸口，让你还能喘口气继续跑。

“你现在算真正完成了黑塔第二层的第一轮炼骨。”塔意道，“从今日起，你可以带着你这副骨头离开塔，去深渊猎场。”

林渊抬眸：“离开？”

“出塔口开一线。”塔意道，“外界只过去一炷香。”

“你可以在深渊里杀一场，带狱源回来，再继续在塔里走时路。”

“塔不养闲骨。”

“你要资源，就去外面抢。”

它的话音一落，炼骨室另一侧的石壁忽然亮起一道弧形门影。

门影上没有【钥】字。

只有一圈圈向外扩散的刻度。

像一只开合的眼。

门影开启的一瞬间，腥冷的风便灌了进来。

那风带着骨丘的腐朽味，带着狱兽的血腥味，也带着修士营地里火堆的烟味。

深渊猎场的气息。

林渊胸口的时间印轻轻一跳。

魔骨黑网也随之低低共鸣。

它们像两只嗅到猎物的兽，提醒他——

真正的修行，不在塔里。

在杀里。

“出去之前。”塔意忽然补了一句。

“记住今天你学的。”

“深渊之力不是给你用的。”

“它是来用你的。”

“你若哪天忘了关门——”

“你就会变成门本身。”

林渊没有回答。

他迈步走向那道弧形门影。

一步。

两步。

每一步都比之前更沉，却更稳。

走到门影前，他回头看了一眼那条细如发丝的幽蓝裂缝。

裂缝安静。

像睡着的蛇。

可他知道，它没睡。

它在等。

等他在深渊猎场里杀得更快、更狠、更重。

等他把更多狱源与血气带回来。

等他某一天不小心，或者不得不，把那扇门再开大一点。

林渊收回视线。

他抬脚踏入门影。

风扑面而来。

远处，兽吼如潮。

更远处，人声隐约。

深渊猎场的夜色在他眼前展开，像一张巨大而肮脏的棋盘。

而他，终于从塔里走出来，重新踏上了棋盘。

只是这一次——

他不再只是棋子。

他要开始学着，去掀棋盘。***  ```
