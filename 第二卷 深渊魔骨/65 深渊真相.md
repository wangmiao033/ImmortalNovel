# 第65章 深渊真相

暗红骨光从裂缝里冲起的那一刻，整片骨山像被谁从内部顶开。

林渊站在裂口前，剑尖还在滴血。

刚经历第一阶段魔骨淬炼的骨骼仍在隐隐作痛，痛感像细锤敲在骨缝里，一阵比一阵深。可他没有停，抬脚便迈入裂缝。

“你身体还没稳。”残魂急道，“再硬闯会把刚淬好的骨头炸裂！”

“不闯就只剩猜。”林渊声音很冷，“我不猜。”

塔意沉默半息，低声道：“进去后先看地，不看顶。真相区外层最先杀的是抬头的人。”

林渊点头，顺着狭长裂道下行。

裂道尽头豁然开阔。

那是一座被骨山与黑链包围的石室，像深渊腹腔里硬生生剜出的一块空洞。四壁全是暗红骨纹，骨纹之间嵌着古狱文，字迹大半被磨平，只剩断裂的笔锋。石室中央立着一座断祭台，祭台上插着半截刑环，环身斩痕密布，像被人连砍了上百刀。

四周地面布着巨大的镇压阵。

阵眼不在中心，而在八个方向的断碑上。每块断碑都被锁链钉死，碑面上有不同时代的血痕，旧血黑，新血红，层层覆盖。

“这不是试炼场。”残魂声音发涩，“这是封禁外层。”

塔意冷冷接话：“更准确点，是维护层。有人在这儿补过封、改过阵、也在这儿死过。”

林渊走到最近一块断碑前，手还没碰到，碑面骨纹就自行亮起。

古音从石室四壁同时响起，机械、冰冷、没有情绪：

“外层核验开启。”

“识别：塔印、钥血、罪印、狱序。”

“非序列者，排斥。”

轰！

镇压阵骤然收紧。

林渊胸口一闷，仿佛有八条无形铁链同时缠上脊骨，猛地向下压。刚淬炼过的骨骼发出细密裂响，膝骨被压得几乎跪地。

“它在把你往外扔。”塔意喝道，“撑住，先让它识别完！”

林渊咬牙，剑插地，硬顶住重压。

血顺着嘴角溢下来，滴在阵纹上。

阵纹微微一颤，颜色从暗红转成深黑，像确认了什么。

古音再次响起：

“钥血共鸣。”

“守狱残序列，疑似匹配。”

“允许停留，限制读取。”

压力松了两分，却没全松。

林渊抬头，眼神沉得像夜。

“允许停留，不让读取？”

“它怕你知道太多。”塔意道，“这就是它的规则。”

林渊冷笑：“那我偏要读。”

他伸手，按上断碑。

冰冷触感刚入掌心，识海里猛地炸开一片残影——

黑色大地被巨阵切成八块，八方都有链柱升起。无数狱修立在链柱间，手持狱令，齐声诵令：“沉渊、立狱、封禁！”

紧接着画面一转，一座完整巨塔从天坠下，塔底压穿山脉，山海塌陷，形成深不见底的渊口。链柱随之下沉，把某种看不清形体的巨大影子拖入渊底。

影子挣扎，天地都在裂。

再下一幕，阵外出现另一批修士，白袍、金纹、古族徽印，他们不是来封，而是来“改”。有人在阵脚刻新纹，有人在碑上抹字，有人把“守狱”二字生生削成“试炼”。

画面戛然而止。

林渊猛地抽手，额角全是冷汗。

“看见了？”残魂声音发抖，“深渊是硬造出来的！”

“是囚场。”林渊低声，“有人把它改成了猎场。”

他话音刚落，祭台上的半截刑环突然自转。

嗡——

整座石室温度骤降，八块断碑同时渗出黑雾。黑雾在半空缠结，化作八道骨灵身影。它们没有人形五官，只有盔甲轮廓和兵器残影，像被规则铸出来的守卫。

“读取超限。”古音响起。

“清除异常。”

“开始。”

八道骨灵同时扑杀。

林渊不退，迎着最前一灵一剑斩出。剑锋穿过骨灵胸口，像斩在冷铁上，震得腕骨发麻。那骨灵后仰半步，反手长枪直刺林渊眉心。

林渊侧头避开，枪锋擦过额角，带下一缕血线。

“不是残念，是阵灵。”塔意道，“它们由镇压阵供能，不打断阵脚就杀不完！”

“阵脚在哪？”林渊一边格挡两侧斩来的刀影，一边问。

“你刚摸的八块断碑！”

“那就拆碑！”

林渊脚下一蹬，直冲东侧断碑。

两道骨灵封路，刀枪交叉拦斩。他不闪，硬顶着一刀从缝里撞过去，左肩被切开一道深口，血当场涌出。林渊趁势贴近断碑，一剑暴劈。

咔！

碑角崩裂。

东侧骨灵顿时暗了一截，动作慢了半拍。

“有效！”残魂吼。

“继续！”塔意厉喝。

可其余七灵攻势更猛。

一灵持链缠踝，一灵重锤砸背，三灵从上方齐压。林渊连吃三击，背骨像被砸散，喉中血气翻涌，险些被压跪。

“这样拆不完！”残魂急道。

林渊抬眼扫过八碑与中央祭台，眸光骤冷。

“不拆八个。”

“拆总控。”

“总控在哪？”塔意问。

林渊盯住祭台刑环下那条最粗黑链。

“那条链就是总阀。”

他猛地转向，直冲祭台。

骨灵们像被触怒，齐齐回防。八道杀影在石室中央交织成网，封死祭台前最后三丈。

林渊没有停。

时间印一亮，把八道杀影在他眼里拉成快慢两层。他抓住两层交错的一瞬，先矮身滑过下盘链影，再抬肘撞开右侧枪柄，最后借左侧锤影的冲力腾空半丈，硬从网缝里挤了进去。

“疯子！”残魂叫。

“管用就行。”林渊咬牙。

他落在祭台边缘，右臂发麻几乎握不住剑。身后八灵已到，刀风贴背。

林渊反手一剑，不斩灵，斩链。

铛——

第一剑，链上只见火星。

第二剑，链节裂出细纹。

第三剑，林渊把全身气血、魔骨黑网与刚淬炼过的骨力同时压进剑锋，低吼着再斩：

“给我断！”

咔嚓！

黑链崩断。

刑环骤停。

八道骨灵动作同僵，随后像被抽走骨架，接连溃散成雾。

石室短暂归于死寂。

林渊单膝跪地，大口喘息，肩背与肋侧鲜血淋漓。可他眼神却更亮，像刚从刀山里捞出一块真铁。

断链之下，露出一枚被遮住的骨匣。

骨匣上刻着完整图腾：神狱塔立于渊口，八链锁渊，下方不是妖兽，而是一团由“骨、血、影”缠成的巨大轮廓。图腾边缘还刻着一行几乎被抹尽的古字：

“深渊者，沉狱之壳。”

“塔在，则封在。”

林渊神色骤沉。

“壳……”他低声，“深渊只是外壳，里面还有东西。”

塔意声音低得可怕：“你终于拼到这一层了。”

“黑塔，不，神狱塔，确实一直在镇压。”

“镇的不是一头兽，也不是一族人。”

“是更早、更脏的东西。”

林渊抬手打开骨匣。

匣内没有宝物，只有半块狱令和一页血浸残简。

狱令上刻“守狱林”三字，最后一字被斩去一半。

残简字迹断裂，却还能辨出几句：

“……守狱一脉，执钥巡封……”

“……血夜前夕，内环已裂……”

“……非外敌独袭，亦有内门反叛……”

“……若后人见此，勿信塔外诸家之言……”

最后一行只有四个字：

“黑塔，仍镇。”

林渊握着残简，指节发白。

“外敌，内叛。”他声音低哑，“林家是两边一起杀的。”

残魂沉默了半天，才挤出一句：“这他娘……比家仇重太多了。”

“我早就知道不只是家仇。”林渊把残简收起，眼神冷到极点，“现在只是证实。”

就在这时，石室四壁忽然齐鸣。

八方断碑残纹同时亮起，比刚才更盛。地面镇压阵开始反向运转，阵心不再向内收束，而是向更深层抽动。

轰——

轰——

轰——

像有一头沉睡万年的巨物在深渊底部翻身。

林渊猛地抬头。

石室顶壁裂开一道纵缝，缝中透出更深层的黑光。那黑光不亮，却让人看一眼就神魂发寒。与此同时，整座黑塔第二层都在共振，锁链声从四面八方传来，越来越重，越来越近。

古音再次响起，第一次带上明显的“急迫”：

“镇压层响应。”

“封禁松动超限。”

“启动黑塔主镇程序。”

塔意在识海里猛然一颤。

“不好。”它声音骤沉，“你拿走骨匣，等于把外层真相钥扣拔了。黑塔主镇被惊醒，下一层会直接开到‘镇压位’。”

林渊握紧剑，盯着顶壁裂缝。

“这不正好？”

“你不是一直说真相在更深处。”

塔意冷声道：“真相在，但命也会被一起收走。”

林渊没有答。

他只是盯着那道裂缝。

裂缝后，隐约有更庞大的锁链影在移动。不是一条两条，是成千上万条，正朝同一个核心收拢。

下一息，一道比石室古音更冰冷的声音，从黑塔更深处传来。

像审判，也像警告：

“黑塔镇压，重启。”*** End Patch
