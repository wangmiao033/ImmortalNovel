# 第62章 上古狱修

“守塔残魂，退下。”

“上古狱修，当面验脉。”

黑门后的声音落下，祭坛上所有狱纹瞬间熄灭一半，又在下一息全数反亮。

那不是震慑，是秩序更替。

狱甲残魂半跪在地，头低得极深：“遵令。”

它不再看林渊，拖着残破狱刀退到祭坛边缘，像一名被收回执法权的旧卒。

林渊盯着门缝。

先是一角狱袍下摆，再是一双黑靴，最后整道身影走出黑暗。

那是一个中年模样的男人，面容苍白，眉间有一道竖裂旧疤，像被某种刑印贯穿过。身上狱袍并不完整，左肩甲碎裂，右臂缠着三圈乌金锁链。锁链并非束缚，反像他身体的一部分，随着呼吸轻轻颤动。

他眼里没有疯意，也没有人气。

只有一种让人本能想后退的冷。

“活的？”残魂声音发哑。

“半活。”塔意低沉，“残躯与执念并存，比残魂难缠十倍。”

那人站定，目光落在林渊胸骨位置。

“塔印、钥血、劫骨……”

“林姓。”

“你不该活着。”

林渊握剑不松：“我活着，才有资格问你。”

“你是谁？”

那人并未立即回答。

他抬手，五指一扣。

轰！

祭坛上方三枚刑环同时转动，无形威压如山崩落。林渊肩背猛地一沉，骨骼咔咔作响，膝骨几乎被压碎。

这股压制不只压肉身。

识海同样一震，神魂像被拖进冰水，连呼吸都慢了半拍。

“第一段，验骨。”塔意喝道，“第二段就会验魂！”

林渊额角青筋暴起，却硬顶着威压抬起头。

“就这？”

他把剑尖狠狠钉进石面，借力站稳。

狱袍男人眼神微动。

“能站。”

“比当年那些伪脉强。”

林渊冷笑：“你口中的伪脉，是谁？”

狱袍男人一步踏前。

地面狱纹自动分开，让出一条直线。他每走一步，锁链就亮一节，祭坛压力便重一分。

“你问题太多。”

“先活过再问。”

话音未落，他右臂锁链骤然弹出。

不是抽击，而是“判缚”。

三道锁链影在空中一分为九，九分为三十六，瞬间封死林渊前后左右所有角度。林渊横剑斩出，斩断七道，剩下的锁链却像有意识一样绕剑而行，直缠手腕。

“缠上就麻烦了！”残魂惊吼。

林渊当机立断，左臂硬顶链影，右腕强拧，剑锋从极小角度反切，贴着自己衣袖斩开一道血口，把缠腕锁链连同血一起甩开。

“你这打法真疯。”残魂吸气。

“不疯，就死。”林渊低声。

狱袍男人看着他掌背流血，眼里掠过一丝极淡波动。

“劫体能扛刑链反噬。”

“难怪……”

他语句未完，掌心已起一枚古印。

印出，祭坛震。

林渊脚下石面浮现一个“狱”字，将他整个罩住。下一瞬，来自四面八方的压力猛地收缩，像要把他直接碾成骨渣。

林渊喉头一甜，血顺唇角流下。

“这是规则印，不是灵力术！”塔意怒喝，“用你自己的印去顶！”

“时间印？”

“对！”

林渊咬牙催动胸骨时间印。

印纹亮起，与脚下“狱”字撞在一起。

一瞬间，世界像被撕成两层——外层是狱修规则，内层是他强行撑开的时间缝隙。两层碰撞处不断迸出细小黑芒，像空间在一点点裂。

狱袍男人眼神第一次真正变了。

“时狱印？”

“你连这个都能唤。”

林渊盯着他：“回答我。”

“林家在你们体系里，到底是什么。”

狱袍男人沉默两息，忽然抬手一压。

两股规则轰然对撞。

砰！

林渊整个人被震飞，背脊撞上断碑，碑体裂开一道长缝。他胸口剧痛，气血翻涌，右臂一阵发麻，几乎握不住剑。

狱袍男人却已贴近。

两人距离只剩一臂。

他灰白眼瞳盯着林渊，声音低得像刀刮铁面：

“林姓。”

“守狱一脉。”

“钥血执门，塔印开禁。”

“血夜之后，本该绝脉。”

“你为何还在？”

每一句都像重锤砸下。

林渊眸色更冷，杀意一点点爬上眼底。

“你问我为何还在？”

“我还想问你——”

“血夜那晚，你们谁在屠林家。”

狱袍男人眼神一沉。

“屠？”

“那不是屠。”

“那是清序。”

“清谁的序？”林渊一步不退，剑锋直抵对方面门，“守狱一脉，还是叛狱者？”

狱袍男人没有答。

他忽然抬手，以指为刃点向林渊眉心。

“你现在，还不够资格问。”

林渊侧头避开，剑锋反撩，斩在对方锁链根部。火星炸裂，锁链纹被他硬生生斩开一道细口。

狱袍男人首次后退半步。

“好。”他低声，“有资格打一场了。”

下一瞬，他周身狱纹全亮。

背后浮现一道巨大的锁链虚影，虚影尽头拖着一扇半开的黑门。门后不见景象，只有无数叠在一起的惨叫与审判声。

“押解印。”塔意声音发沉，“上古狱修的核心印之一，他动真格了。”

林渊也不再留手。

魔骨黑网全开，时间印催至极限，太初劫体气血如潮涌动。剑意在周身凝成一条细长锋线，直指狱袍男人咽喉。

“来。”

两人同时动。

狱袍男人一掌拍下，押解门影随掌压落。林渊迎着门影冲上，剑锋在半空拉出一道扭曲轨迹，硬生生从门影中斩出一线空隙。

轰！

掌剑相撞，祭坛第六层直接塌陷一角。

林渊左肩再中一击，骨裂声清晰可闻。可他借震力转身，第二剑反切对方腰侧。狱袍男人锁链回卷，拦下剑锋，却被剑意震得锁链轻颤。

“你的剑，带狱意。”狱袍男人低声，“谁教你的。”

“死人教的。”林渊冷笑，“你们塔里死太多，不缺老师。”

狱袍男人眼神更冷，锁链暴起成网，将林渊整个人罩住。

这网不是困身，而是抽神魂。

林渊只觉得识海猛地一空，像有东西要被硬扯出去。耳边瞬间响起无数碎片声：

“守狱者听令——”

“叛狱者诛——”

“林氏外门封绝——”

“钥血移交——”

声音乱成一团，真假难辨。

“别被拖走！”塔意暴喝。

林渊猛咬舌尖，血腥味炸开，神智回拢。他反手把剑插进自己脚边石面，借这一顿稳住识海，然后沿剑身灌入全部剑意。

“给我开！”

剑意自下而上爆开，锁链魂网被撕出一道豁口。

林渊趁豁口前冲，贴身撞进狱袍男人怀中，左肘狠砸其胸口旧伤，右剑直刺那道竖裂旧疤。

狱袍男人抬手去挡，慢了半拍。

嗤！

剑尖刺入旧疤半寸。

灰白血线溅出。

狱袍男人闷哼，第一次被逼退三步。背后押解门影随之震荡，门缝里一枚黑色令片掉落，砸在地上。

林渊眼疾手快，一把抓住令片。

令片入手冰冷，上刻两字：

“时狱”。

背面还有半句残文：

“欲问狱源，先行时狱之路。”

林渊瞳孔一缩。

“时狱之路……”

狱袍男人稳住身形，看向林渊掌中令片，眼神终于有了真正的杀意。

“把令还我。”

“这是钥引，不是你现在能持的东西。”

林渊握紧令片，血顺掌缝滴落。

“你越不让我拿，我越要拿。”

“想要，自己来抢。”

狱袍男人沉默一瞬，忽然收起杀意。

他盯着林渊，声音冷得像最终审判：

“你来得太早，也太晚。”

“早在封禁未全松。”

“晚在守狱已崩塌。”

“林姓后人，若你真想追到血夜根处——”

他抬手，指向祭坛更深处。

黑暗被无形力量撕开，一条古路缓缓浮现。

那路由断阶、锁链、刑纹交织而成，路面时而清晰时而扭曲，像被不同时间层反复碾过。路两侧挂着无数断裂刑牌，刑牌上名字全被抹去，只剩斩痕。

“走时狱之路。”

“路尽头，有你想要的答案。”

“也有你最先要看的——”

狱袍男人盯着林渊，一字一顿：

“林家的死。”

话音落下，他身形开始虚化。

并非败退，而像主动撤回某道更深层规则里。狱甲残魂也随之低头，连同祭坛上大半狱纹一起熄灭。

林渊刚要再问，古路尽头忽然传来更沉的锁链轰鸣。

咚——

咚——

每一声都比刚才更重，像有巨物在路底拖行。

紧接着，一串极慢的脚步声自黑暗深处响起。

一、二、三……

脚步未至，威压先到。

林渊胸骨时间印猛地一颤，掌中“时狱”令片同时发烫，令面纹路自行亮起，像在回应来者。

黑暗尽头，一道更高大的狱袍轮廓短暂显形。

那人肩披完整刑环，背负七节重链，气息比眼前这位狱袍男人更加古老，也更加完整。

他没有走近，只在黑暗里停了一息，声音穿过整条古路，冷冷落下：

“时狱未净，何人提前启令。”
