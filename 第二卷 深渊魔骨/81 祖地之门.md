# 第81章 祖地之门

石厅顶部轰鸣未停，林渊却先一步收起石匣中的半焦簿页、门印碎片与留影石。

“上面的人还在压。”塔意低声，“你要么现在走，要么被他们堵死在暗层。”

林渊抬眼，看向石厅北壁那道被血光勾勒出的细缝。

“老祖说真正的门在祖地更深处。”

“那就走这道缝。”

他把白纹使者的尸体踢进石台裂口，反手按在北壁族纹上。腕上旧印与壁上主纹同亮，石缝轰然扩开，一道向下石门露出半边。

门后冷风像刀，夹着极淡的铁锈味。

同时，头顶传来急促脚步。

“就在下面！”

“赵家那边说了，必须抢在林渊前面开门！”

“杜统领死了，白纹使者也断了，谁拿到祖地门谁就上位！”

林渊冷笑：“果然一群闻血就来的狗。”

石门未全开，他已侧身钻入。刚下三步，背后暗层入口被人强行轰开，十余道气息同时压来。

“林渊，留下匣子！”

林渊回头，站在狭长石阶上，剑锋一横。

“再进一步，拿命填。”

最前两名赵家修士扑下，林渊一剑斩断前者膝骨，反手刺穿后者喉咙。狭道太窄，后方人马无法展开阵型，只能硬挤。林渊借地势连斩，三息内再杀四人，尸体滚落，把台阶堵成血坡。

“退！先退！”

“他在卡口！”

“放毒烟！”

白纹散修丢下三枚毒雾弹。青烟翻涌而下，林渊腕印微热，墙中族纹骤亮，烟气竟被古阵反抽，倒卷回去。

“啊——我的眼！”

惨叫四起。

林渊不恋战，转身下冲。石阶尽头是一座圆形石门，门面刻着半毁字句：

“林氏执钥，非血不启。”

他掌心按上门环，鲜血顺纹路蔓延。石门震动，门缝里涌出一道灰白光，先扫他骨，再扫他魂，最后停在右腕旧印。

古音响起：

“林姓支脉。”

“旧印匹配。”

“祖地之门，准开。”

石门缓缓转开。门后不是地窖，而是一条巨大的地下廊桥。廊桥尽头，隐约能看见一座被黑土埋了半截的古门，门上挂着林家主旗残片，旗边还缠着神狱细链。

林渊眸色骤沉。

“林家祖地，果然不在地面。”

背后杀声已逼近。

他迈步入门，石门在身后自行闭合。闭合前一瞬，顶上传来一道怒吼：

“林渊！你跑不了！”

石门合死，声音断绝。

前方古门却忽然微震，门缝里传来低沉的、像哭又像笑的风声。*** End Patch
