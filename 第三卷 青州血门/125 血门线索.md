# 第125章 血门线索

祖祠内外全是人。

赵家、杜家、白纹、黑市暗盟、城防暗线，五方修士把祠街堵得水泄不通。可真正能进祠堂的，仍只有那几家核心人手。

林渊潜到祠后高墙，先听见争吵。

“血门线索在祖牌下，不在你杜家手里！”

“放屁，后簿残页写的是城外禁山！”

“都闭嘴，白使者说了，先拿林家旧令再定方向！”

林渊眸光一沉。

禁山。

这就是下一坐标。

他正要下墙，一道熟悉声音从祠中响起：

“林渊，你不用藏了。”

“你要的线索，我给你看。”

说话的是赵青崖——肩上缠带，显然还没死透，只是换了替身死讯。祠堂门被推开，赵青崖站在祖牌台前，手里举着一片血色薄石。

“门印映石。”他笑得阴冷，“里面有血门方位。”

“你进来拿。”

林渊落地入院，剑锋不偏。

“你真不怕死。”

“怕。”赵青崖点头，“所以我带了这么多人给你陪葬。”

他一挥手，祠堂四角杀阵同时亮起。杜家刀阵封前，白纹锁阵封后，黑市弩阵居高压顶。

“杀！”

林渊不退，先冲赵青崖。

第一道刀阵落下，他硬切中轴，连斩两名刀手，借尸体挡弩。白纹锁链缠来，他腕印外放门环纹，反缠回阵师脖颈，一剑封喉。

赵青崖趁乱后撤，掐碎映石。

映石在空中炸出一幅短暂地图：青州城西北禁山腹地，有一圈血色环线，中央标着两个古字——“血门”。

所有人眼睛都红了。

“禁山！真在禁山！”

“先杀林渊，再去血门遗址！”

林渊抓住地图残影，将方位刻进识海，随即一剑穿过赵青崖左肩，把他钉在祖牌旁。

“你命真硬。”

赵青崖咳血冷笑：“硬的不止我，局也硬。你去禁山，就再也不是青州小斗了……”

黑纹亮起。

林渊当机立断，抬手一掌震碎他喉骨，抢在禁口前逼停。

院里众人见赵青崖倒地，瞬间大乱。

林渊没恋战，连杀四人开路，翻墙离去。

夜色下，禁山方向的天幕忽然闪过一线红雷。*** End Patch
