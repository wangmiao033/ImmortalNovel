# 第127章 猎手现身

林渊刚进遗址外环，身后山雾忽然齐齐下压。

不是自然雾，是人为封口。

十二道黑影从雾里无声落下，清一色暗灰短袍，胸口绣着极小门环纹。为首之人戴骨面，手持细长锁钩，声音平直得像刀背：

“门印猎手，奉令收钥。”

“林渊，束手。”

林渊扫了一眼。

这批人和赵杜白纹完全不同——不喊、不乱、不争嘴，站位像刀阵，眼里只有任务。

“终于来了点像样的。”林渊淡声。

骨面首领抬手：

“活捉优先。”

“断四肢，不伤印。”

十二猎手同时动。

三人锁步，四人封腕，两人压喉，剩余三人在后抛出网形印器，配合精确到可怕。林渊第一轮就吃了亏，右腕被两道细链擦中，旧印灼痛骤起。

“他们专打你的印。”塔意低喝。

林渊时间印一开，脚下连错五步，硬从包围中心撕出一线。可猎手们不追杀，只追“控位”，逼他回到网器覆盖区。

“专业。”残魂低声骂。

“那就先斩指挥。”林渊盯住骨面首领。

他故意后撤半步，引三名锁步猎手前压，随后突然前冲，剑锋走极短线连断两链，借反弹力跃向首领。首领抬钩格挡，钩剑碰撞几乎无声，却各自退半步。

“比我想的快。”首领道。

“你比我想的脆。”林渊回道。

第二轮交手，林渊不再跟阵走，反而主动进网，让网器锁住自己左肩，借锁力把首领硬拖近身，剑柄砸面，反手刺喉。

首领偏头让过致命位，喉侧仍被划开一线，血第一次流出。

猎手阵势瞬乱半拍。

林渊抓住半拍，连续斩翻四人，再一脚踢碎网器核心，封锁区当场失效。

首领后退，眼神终于变了。

“你已接近旧序列战斗范式。”

“果然是钥脉。”

林渊剑尖下垂，冷声逼问：

“谁派你们来的。”

首领沉默一瞬，忽然笑了。

“旧脉来人，想见你。”*** End Patch
