# 第129章 血路开封

薛沉给的半图是一块血色兽皮，边角焦黑，只剩中段线路。

线路终点标着两个字：血路。

林渊用旧令对上遗址石门残框，门框内壁立刻浮出完整路径。两块图拼合，正好补齐一条向地底延展的螺旋通道。

“你果然藏了图。”林渊冷声。

薛沉不否认：“你也藏了簿页。彼此彼此。”

通道开启前，遗址外围突然响起号角。

赵杜白三方援兵到了。

“围死遗址！”

“别让林渊入血路！”

同一时间，通道口也亮起血色禁纹，开始血脉审查。非林血者脚一踩就被反噬。两名猎手试探上前，刚触线，腿骨当场炸裂。

“血路不是谁都能走。”塔意道。

林渊看向薛沉：“你进不了。”

薛沉面无表情：“我送你到口。”

外敌已压到门前。

林渊不再废话，提剑先杀。

遗址窄道里，战斗比城中更狠。林渊以一敌多，突破后剑势完全放开，三步一杀。薛沉和门印猎手也在后方挡线，但明显留了余力，像在观察林渊到底能走多远。

白纹阵师想炸通道口，林渊一剑先断阵盘，再补一脚把人踹进血纹禁线。禁线爆起，瞬间把他烧成灰骨。

赵家弩队从高处压射，杜家重盾正面推墙。林渊借断墙翻身跃上弩台，一剑斩翻四人，再把弩架推落，砸进杜家盾阵中心。

“开路！”薛沉低喝。

林渊抓住空档，直冲通道口，把旧令按进血纹槽。

血路轰然亮起。

地底深处传来低沉机括声，像古门一层层解锁。通道里吹出冰冷血风，风中混着遥远城音——钟鸣、喊杀、雨声。

林渊瞳孔微缩。

“青州那边出事了。”

薛沉也听见了，脸色首次微变：

“这是城防钟。”

“夜雨围城，提前了。”*** End Patch
