# 第110章 祠堂杀局

子时，林家祖祠。

雨落得很密，祠堂外却没有雨声。

因为整座祠堂被一层无形阵幕罩住，雨点落在阵幕上只化成细白烟。阵幕内，赵、杜、白三方人马各占一角，彼此刀未出鞘，杀意却已满场。

祠堂中央，祖牌台前摆着一张血色名单。

名单被阵纹托在半空，字迹忽明忽暗，像随时会散。

赵青崖站在北侧，笑意薄冷：

“林渊会来。”

“他不来看这份名单，就不是林家后人。”

杜寒川扛刀立在南角，嗓音粗沉：

“等他进阵，先断腿，再取血。”

白纹使者没露全脸，只露一双眼：

“别忘了规矩。祖牌第一锁，必须活血触发。”

“谁先坏规矩，谁先死。”

话音刚落，祠堂大门被人一脚踹开。

林渊提剑而入，雨水顺着发梢滴在地砖上，眸光冷得像冰。

“规矩？”

“你们也配在林家祠堂讲规矩。”

赵青崖笑了。

“你果然来了。”

“名单就在这，想看，先拿命换。”

白纹使者一挥手，阵幕瞬间闭死。外界声音被全部隔绝，祠堂化作封杀笼。

“动手。”

三方同时出杀。

杜寒川先冲，重刀如山砸落。林渊侧步让刀，反手一剑切其腕侧，杜寒川吃痛后退。赵青崖从侧线突袭，骨牌在掌，门印之力直压林渊右腕。

林渊腕印一震，门环纹外放，硬把骨牌压偏半寸。

“又是你这破牌。”林渊冷喝，剑锋直指赵青崖咽喉。

白纹使者则在后方落笔，祠堂四柱同时亮起封脉纹，想锁死林渊步法。林渊脚下一顿，时间印开半拍，硬在封脉纹合拢前切进阵眼盲区，一剑斩断东柱纹线。

整阵晃动。

“先杀白纹！”赵青崖突然厉喝。

杜寒川一愣：“你疯了？”

“他要独吞第一锁！”赵青崖吼。

三方瞬间乱斗。

林渊抓住这瞬间，直冲祖牌台。杜寒川回刀拦截，林渊硬顶刀背，一记肘击撞开其胸口，再一剑抹过赵青崖肩颈，逼他退开。

白纹使者怒声：“你们这群废物！”

他抬手引爆祠堂顶部备用符阵，想同归于尽抢开锁时机。林渊眼神一厉，反手甩剑钉穿其掌心，符阵提前失控，炸在半空。

轰！

祠堂梁木坠落，血灯再亮。

祖牌台三十六牌同时震鸣，血名单在半空骤然展开。林渊一把抓住名单，目光一扫，瞳孔瞬间收缩——

名单上不仅有赵、杜、白三家的符号，还有一列被刮花的林姓名字，末尾留着一行血字：

“血夜开门者，藏于林内。”

“原来……真有内手。”林渊声音冷得发抖。

赵青崖见状，狞笑着扑来：“把名单交出来！”

林渊回身一剑，直接贯穿他肩膀，把人钉在祖牌台边缘。

“你先回答。”

“内手是谁。”

赵青崖吐血狂笑：“想知道？去祖牌下面问你林家祖宗！”

他话音未落，后颈黑纹亮起。

林渊眼神一沉，拔剑后退。

砰！

赵青崖后颈炸裂，血溅祖牌。

同一瞬，祖牌台下地砖全部崩开。血灯火苗暴涨一尺，族纹沿地面疯狂蔓延，汇向祠堂中央。

机括声从地底深处层层传来。

像一扇封了很多年的门，终于被这口血与这份名单一起推开。*** End Patch
