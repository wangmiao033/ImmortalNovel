# 第123章 门印碎痕

城西废井下方，埋着一截断碑。

林渊用旧令触碑，碑面立刻浮出一圈残缺门印纹，纹路像被利器强行剁开，断口处还残着干涸黑血。

“这就是门印残基。”塔意道，“当年有人在这里硬拆过。”

林渊刚俯身细看，周围屋脊同时亮起十几道火点。

“别让他拓印！”

“杀！”

赵、杜、白三方人马一齐压来，显然早在蹲守。白纹阵师先手布网，杜家刀手正面冲阵，赵家弩手高位封后路，杀局比前几次更紧。

林渊收令入袖，抬剑迎杀。

第一波刀阵刚到，他便贴地切入，剑锋先断中轴持刀者，再反挑左翼咽喉。白纹网落下时，他腕印一震，门环纹短暂外放，把网线逼偏半寸。

“又是这印！”白纹阵师厉喝，“锁他腕——”

林渊一剑破阵，直取阵师。阵师后撤掐诀，赵家弩钉齐射掩护。林渊硬吃一钉入肩，借痛冲近，一剑劈开阵师额骨。

杜家头目怒吼着重刀横斩。林渊不闪，双手握剑正面硬碰，火星爆开，刀身当场崩裂。第二剑紧跟，头目胸前开出一道深口，重重跪地。

“门印……到底在找什么？”头目咳血。

林渊踩住他肩骨：“谁让你们守这碑。”

“赵青崖……说这里会出血夜残影……”

话音未落，断碑门纹骤亮。

一段极短残影在井底浮现——

雨夜、祠门、林家长辈持令死战，有人从内侧拉开一条暗门，白纹袖修士趁缝而入。

残影一闪即灭。

林渊瞳孔骤缩，脚下力道更重。

“内门真是从里面开的。”

地底忽然轰鸣，城中多处钟声同时响起。

青州，开始震了。*** End Patch
