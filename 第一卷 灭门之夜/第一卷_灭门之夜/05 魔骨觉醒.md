# 第5章 魔骨觉醒

林渊掌心朝上，血滴落下，被符纹吞没。符纹一亮，背脊那道空位就像被铁钩轻轻一拽，痛得他眼前发黑。

“别缩。”黑影冷笑，“缩回去，你就死。”

林渊没缩。他抬着手，喉咙里挤出一声哑问：“现在开始？”

“从你伸手那刻起就开始了。”

哗啦——！

九根黑柱轰鸣，锁链同时绷紧，石室中心那截暗金骨影像被唤醒，暗金纹路一寸寸亮起，暴戾的魔意瞬间压下，连空气都像变沉。

下一瞬，一道黑光如针，直刺林渊背脊空位！

“呃啊——！”

林渊腰背猛地弓起，痛从骨髓炸开，像滚烫铁水被灌进空洞里。他眼前一黑，差点当场昏死，却被黑影一句话硬生生拽回——

“别晕。你要承的，是骨，不是福。”

第二道黑光落下，第三道紧随其后。林渊跪倒在地，额头砸在石面上，血从唇角溢出。他双手撑地，不让自己趴下，声音像从牙缝里磨出来：“继续。”

黑影笑了一声：“好。”

锁链一震，暗金骨影化作一股更粗的黑光，轰然灌入他背脊！

轰——！

林渊体内经脉本就破碎紊乱，此刻被那股魔意强行撬开、撕裂、再缝合。每一寸经络都像被拉直后用刀刮过，疼得他浑身痉挛，手指抓碎石面上的砂砾。

更可怕的是背脊。

那道被挖空的“位”，像一张张开的伤口。魔骨之力灌入后，不是简单填满，而是像某种活物在里面“咬合”。他能清晰听见骨与骨对接的细响，咯吱、咯吱，像在把他重新拼起来。

痛感一波波推上来，像潮水拍碎堤坝。林渊眼前不断闪白，胸口抽搐，喉咙里涌出血沫，他却硬生生把血咽下去。

“撑住。”黑影低笑，“你太初劫体再硬，也挡不住你自己先崩。”

林渊咬牙抬头，眼里血丝密布：“我崩不崩，轮不到你决定。”

话音落下，他猛地一吸气，像是把所有痛都吸进肺里，再一口吐出。他用意志强行把乱窜的魔意压回经络，不让它在体内胡乱撕咬。

那一瞬，魔骨意志明显一滞。

识海也被硬生生撞开一道缝。

无数碎片画面扑来：白骨铺地、血海翻涌、古老宗门崩塌……最后，一只巨大的黑色瞳孔在血海上方睁开，冷漠又饥饿。

“你配承我骨？”那意志低语。

林渊抬起满是血的脸，眼神却冷得像刀：“你不承我，我就承你。”

他用恨当锚，把神魂往前硬推一步。

就是这一步，像把闸门踹开——

嗤。

一缕极淡的黑气从背脊空位冒出，沿着新被撬开的经脉游走一圈，最后沉入丹田。

疼仍在，可那疼里第一次混进了“力量”的回响。

林渊浑身一震，像被什么点燃。那缕魔气落入丹田后并未安分，反而绕着丹田壁打了个旋，冷冽得像寒星，却带着锋利的吞噬欲。

他呼吸一滞，胸口的剧痛竟被压下去一丝，手脚也从麻木中恢复了些许知觉。可下一刻，背脊空位又传来一阵更深的刺痛——像在提醒他：这不是恩赐，是枷锁的第一环。

林渊猛地睁眼，瞳孔深处掠过一丝幽暗。他低头看向手背，细密暗纹若隐若现，随呼吸明灭，像鳞，像符。

“第一缕魔气。”黑影在高处低笑，“从今天起，你不再是空壳。”

林渊喘着粗气，声音沙哑，却稳得可怕：“我只问——它能让我杀回去吗？”

“能。”黑影淡淡道，“前提是你别被它反噬吃空。”

林渊缓缓握拳，指节发响。他能感觉到，经脉虽然仍残破，却被强行“拢”出一条能走气的路；那条路很细、很痛，但确实存在。

他抬头，盯着石室中心：“那就让它吃不空。”

话音落下，九柱符纹忽然一暗，锁链缓缓松弛。可石室中心却传来更清晰的一声“咔嚓”——像封印裂开一道缝。

林渊背脊一热，魔骨在体内轻轻蠕动，像活物在适应他的血肉；与此同时，石室更深处传来更沉的锁链声，仿佛还有别的东西被这缝隙惊醒。

黑影的声音贴着他识海落下，带着一丝玩味：

“听见了吗？你醒了，深渊就会来找你。”
